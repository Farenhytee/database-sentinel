## Fixes (all prompted by test-run failures, diagnosed on dev only)
1. **Tool errors:** go back to the model (`ToolNode(handle_tool_errors=True)`) instead of ending the audit.
2. **Timeouts:** OpenRouter now uses `provider.sort=throughput`. Slow providers had pushed B0's 2–9k-token outputs past the 300s deadline.
3. **Extraction:** LangGraph's final structured-output step never sees the system prompt. It turned dismissed candidates, and even "no finding" tables, into findings (6/6 dev captures had correct final text). It now gets its own instruction (`EXTRACT_PROMPT`).

## Still open
- A still passes rule candidates through on clean cases sometimes (`private.is_admin`, `storage.listing-images`), though less often: 0–2 FPs per run on the 3 dev clean cases, versus 1–6 before the fix.
- Misses vary between runs: `MASS_ASSIGNMENT` on 013, `MULTIPLE_PERMISSIVE` on 008.
